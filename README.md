# 渡渡鸟电竞 · 价格表网站（融合版）

对 <https://dduniao.com/> 的复刻，并融合了参考页面（辰兴电竞价格表）的版式。
**纯静态网站：不需要服务器、不需要数据库、不需要安装任何软件**，双击就能打开。

配套一个**可视化后台**（`admin.html`），改文字、换图片、调价格都不用碰代码。

---

## 一、先看这里：三个入口

| 文件 | 干什么用 | 谁会用 |
| --- | --- | --- |
| **`admin.html`** | 可视化后台：改文字 / 换图片 / 改价格 / 改客服微信 | ★ 日常就用这个 |
| **`index.html`** | 网站前台，双击就能看效果 | 你的访客看到的就是它 |
| `service.html` | 老链接兼容页，会自动跳到新地址 | 一般用不到 |

**日常改内容的标准动作**：双击 `admin.html` → 左边点栏目 → 右边改 → 第 ⑤ 步保存 → 刷新 `index.html`。
详细图文步骤见 **[新手操作手册.md](新手操作手册.md)**。

> 🔒 `admin.html` 以及它的 `admin.js` / `admin.css` **只保留在本地，不随仓库发布**（见 `.gitignore`）。
> 后台是给你自己用的本地工具，放到公网上没有任何好处。

> 🛡️ 后台**每次保存前会自动存一份**（最多 8 版），存在你浏览器里。
> 误删了分类 / 玩法，或者存了一版不满意的，去 **⑤ 保存与发布 → 自动存档（后悔药） → 恢复这一版** 即可。

## 二、文件结构

```
dduniao-clone/
├── index.html                  ← 网站前台（结构骨架）
├── admin.html                  ← 可视化后台
├── service.html                ← 老链接跳转页
├── README.md                   ← 本文档
├── 新手操作手册.md              ← 手把手教你怎么改内容
├── 上线部署指南.md              ← 怎么让别人在公网访问
├── _v1备份/                     ← 改造前的旧文件（已不用，留着以防后悔）
└── assets/
    ├── css/
    │   ├── base.css            ← 设计变量、重置、字体、动画（改配色看这里）
    │   ├── layout.css          ← 各区块版式：轮播/标签/海报/页脚/弹层
    │   └── admin.css           ← 只有后台用
    ├── js/
    │   ├── data.js             ← ★ 内容数据（后台生成，勿手改）
    │   ├── config.js           ← ★ 站点设置（后台生成，勿手改）
    │   ├── main.js             ← 前台渲染引擎（勿手改）
    │   └── admin.js            ← 后台逻辑（勿手改）
    └── images/                 ← ★ 全部图片素材
        ├── banner-header.png           顶部主视觉
        ├── banner-footer-notice.png    底部「板板须知」长图
        ├── page-background.jpg         页面底色图
        ├── default-avatar.svg          图片丢失时的兜底图
        ├── favicon.ico                 浏览器标签页小图标
        ├── covers/                     9 个分类的封面图
        ├── <分类>-<序号>-<含义>.*       各玩法的小图标
        └── detail/<玩法id>.jpg          各玩法的价目表大图
```

> **只有 `assets/images/` 里的图片和后台保存出来的两个文件需要你操心。**
> 其它文件都可以当作「程序」，不用动。

**脚本加载顺序不能调换**（前台页面末尾）：

```html
<script src="assets/js/data.js"></script>    <!-- 1. 内容 -->
<script src="assets/js/config.js"></script>  <!-- 2. 设置 -->
<script src="assets/js/main.js"></script>    <!-- 3. 渲染 -->
```

## 三、这一版改了什么（融合设计说明）

原来的复刻是「dduniao 原站 1:1」，共 4 个区块。这一版保留了它的素材与视觉识别，
把参考页面的版式和交互融了进来。

### 3.1 沿用了 dduniao 的部分

| 内容 | 说明 |
| --- | --- |
| 全部图片素材 | 顶部主视觉、板板须知长图、9 个分类封面、25 个玩法图标与价目表大图 |
| 全部文案 | 分类名、玩法名、页脚 5 行宣传语、公众号、备案号、版权 |
| 视觉识别 | 粉 / 蓝卡片配色、毛玻璃、圆角阴影、渐变条 |
| 页脚 | 紫色渐变卡片 + 金色高亮 + 联系方式 + 备案区 |

### 3.2 从参考页面引进的部分

| 新东西 | 解决什么问题 |
| --- | --- |
| **顶部轮播** | 原站只是一张静态大图；现在可放多张自动轮播，点图直达对应分类 |
| **吸顶胶囊导航** | 原站没有导航栏，25 个玩法散在长页面里；现在一点直达 |
| **三层信息结构** | 分类 → 玩法 → 详情，手机上一屏就能切换 |
| **海报卡** | 玩法名 + 价格盒 + 规则，文字版信息比纯图片好读得多 |
| **价格盒** | 原站价格只能看图；现在可以填成文字（¥70 /h 这样的大字） |
| **底部固定按钮** | 「复制客服微信」+「点我下单」，任何位置都能一键触达 |
| **下单弹层** | 二维码 + 微信号 + 一键复制，手机上不用来回切 App |
| **图片放大** | 价目表和板板须知点击全屏看，手机上终于看得清了 |
| **粉紫渐变底色** | 参考页的色调，比原站灰粉底更活泼 |
| **分享锚点** | `index.html#cat=分类id&item=玩法id`，可以直接把某个玩法发出去 |

### 3.3 有意保留的差异

- 原站首页**没有轮播、也没有导航栏**，这一版是按你的要求新增的，不是复刻错误。
- 原站底部「板板须知」图宽度 1280px，在 768–1279px 宽度下会溢出产生横向滚动条（原站自身的样式缺陷）。
  这一版补了 `max-width:100%`，因此平板端页面总高与原站不同，其余全部一致。

## 五、本地运行方式

### 方式一：直接双击（推荐，零依赖）

双击 `index.html` 即可。本站**没有任何网络请求**，`file://` 协议下功能完全正常。

### 方式二：本地静态服务器（可选）

```bash
# Node.js
npx serve dduniao-clone

# Python 3
python -m http.server 8080 --directory dduniao-clone
```

然后浏览器访问 <http://localhost:8080/>。

> 建议 Chrome / Edge / Firefox 最新版。页面使用了 `backdrop-filter`、
> `aspect-ratio`、CSS 变量等现代特性。

## 六、技术说明

### 6.1 技术选型

**原生 HTML + CSS + JavaScript，无框架、无构建步骤、无后端。**

- 前台 `main.js` 用 ES5 语法写成，兼容性最好；
- 后台 `admin.js` 用 ES6，只在你自己的浏览器里跑；
- 不用 `fetch` / `XMLHttpRequest`，因此 `file://` 下没有跨域问题；
- 动态内容全部用 `createElement` + `textContent` 构建，不存在 HTML 注入风险。

### 6.2 唯一的外部依赖

顶部会尝试加载一个手写体字体（`miaoda.feishu.cn`）。

- 联网时：标题显示为可爱的圆体；
- 断网时：自动回落到系统黑体，**不影响任何功能**。

想完全离线的话，把 `index.html` 里那行 `<link rel="stylesheet" href="https://miaoda.feishu.cn/...">` 删掉即可。

### 6.3 响应式断点

| 断点 | 版心 | 说明 |
| --- | --- | --- |
| < 768px | 100% | 手机：满宽，轮播 4:3，页脚联系方式单列 |
| 768 – 1199px | 720px | 平板：居中收窄，分类卡片 2 列 |
| ≥ 1200px | 880px | 桌面：轮播 21:9 满宽，分类卡片 2 列 |
| ≥ 1600px | 960px | 超宽屏：略微放大版心 |

另外做了 `prefers-reduced-motion` 无动画降级。

### 6.4 交互一览

| 交互 | 表现 |
| --- | --- |
| 轮播 | 自动播放（可关）、左右箭头、指示点、鼠标悬停暂停、点图跳分类 |
| 顶部分类标签 | 点击切换，URL 锚点同步，刷新后停在原处 |
| 玩法胶囊 | 点击切换玩法，海报和价目表同步更新 |
| 价格盒 / 分类卡 | 悬停上浮、阴影加深 |
| 底部按钮 | 复制微信号（成功 / 失败都有提示）；点「下单」弹出底部弹层 |
| 弹层 | 点遮罩或 `Esc` 关闭 |
| 图片放大 | 点价目表 / 板板须知全屏预览，`Esc` 或点背景关闭 |
| 图片加载失败 | 自动换成兜底头像，不会出现碎图 |
